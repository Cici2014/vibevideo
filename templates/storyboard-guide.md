# 专业分镜脚本编写指南

## 分镜脚本核心要素

专业分镜脚本应包含以下要素，确保画面、声音、节奏的完整描述：

### 1. 景别（Shot Size）
- **远景 (Long Shot)**: 展现宏大场景，强调环境
- **全景 (Wide Shot)**: 展现完整场景和主体全貌
- **中景 (Medium Shot)**: 展现主体上半身，突出动作和表情
- **近景 (Close Shot)**: 展现主体局部，强调细节
- **特写 (Close-up)**: 聚焦关键细节，增强视觉冲击

### 2. 镜头技巧（Camera Movement）
- **固定 (Static)**: 镜头固定不动
- **推镜 (Dolly in)**: 镜头向前推进，强调主体
- **拉镜 (Dolly out)**: 镜头向后拉远，展现环境
- **摇镜 (Pan)**: 水平转动，跟随动作或展现横向空间
- **倾斜 (Tilt)**: 垂直转动，展现纵向空间
- **环绕 (Orbit)**: 围绕主体旋转，多角度展现
- **跟随 (Follow)**: 跟随移动对象，保持相对位置
- **升降 (Crane)**: 垂直升降，改变视角高度

### 3. 镜头角度（Camera Angle）
- **平视 (Eye Level)**: 正常视角，自然真实
- **俯拍 (High Angle)**: 从上往下，显得主体渺小或展现全貌
- **仰拍 (Low Angle)**: 从下往上，显得主体高大或增强气势
- **鸟瞰 (Aerial)**: 垂直向下，展现布局和空间关系
- **倾斜角度 (Dutch Angle)**: 倾斜画面，营造紧张或不稳定感

### 4. 画面内容（Visual Content）
- **场景/环境**: 具体位置、室内/室外、背景细节
- **主体**: 主要对象（人物、产品、物体）的外观、姿态、表情
- **光线**: 光源方向、强度、色调（暖/冷）、时间（晨/午/夜）
- **动作**: 画面中的动态元素（人物动作、物体移动、自然现象）
- **构图**: 主体位置、画面平衡、视觉焦点

### 5. 音效设计（Sound Effects）
- **环境音效**: 风声、雨声、鸟鸣、城市噪音等，营造场景氛围
- **动作音效**: 脚步声、门关声、物品碰撞声等，增强动作真实感
- **特殊音效**: 爆炸声、魔法效果声、科技音效等，突出特定情节
- **音量控制**: 明确音量大小、音调高低、音效位置（前景/背景）

### 6. 背景音乐（Background Music）
- **音乐类型**: 轻快、舒缓、紧张、激昂等
- **音乐情绪**: 与画面情绪匹配，增强情感表达
- **音乐节奏**: 快慢节奏，与画面节奏协调
- **音乐起止**: 渐入/渐出、突然切入等

### 7. 时长（Duration）
- 明确标注每个镜头的时长（秒）
- 控制整体节奏，确保信息传达充分

## 专业分镜脚本格式示例

### 标准格式
```markdown
# 镜号：01 | 场景：咖啡馆清晨

- **景别**: 特写 (Close-up)
- **技巧**: 推镜 (Dolly in)
- **角度**: 平视 (Eye Level)
- **时长**: 5秒

**画面内容**：
一个精致的白色咖啡杯放在深色木质桌面上，杯中升起缕缕白色蒸汽。
柔和的自然光从左侧窗户洒进来，在桌面上投下温暖的光影。
镜头从咖啡杯上方缓慢推近，最终定格在咖啡杯特写，背景逐渐虚化。
整体色调偏暖，氛围宁静、温馨，充满清晨的美好感。

**音效**：
- 环境音：轻柔的咖啡店环境音（音量：30%）
- 动作音：咖啡机低沉的嗡嗡声（音量：40%）
- 背景音：远处轻微的谈话声（音量：20%，模糊处理）

**音乐**：
- 类型：轻柔的爵士乐或轻音乐
- 情绪：温馨、放松
- 节奏：缓慢（BPM: 60-80）
- 处理：渐入，音量控制在20%

**备注**：确保蒸汽效果自然，光线柔和，避免过曝。
```

### 简化格式（推荐）
```markdown
# 咖啡馆清晨特写

- **景别**: 特写
- **技巧**: 推镜
- **时长**: 5秒

精致的白色咖啡杯放在深色木质桌面，蒸汽缓缓上升。
柔和的晨光从左侧窗户洒入，镜头缓慢推近至咖啡杯特写。
色调温暖，氛围宁静温馨。

**音效**：咖啡店环境音（30%），咖啡机嗡嗡声（40%），远处谈话声（20%，模糊）

**音乐**：轻柔爵士乐，渐入，音量20%，BPM 60-80
```
