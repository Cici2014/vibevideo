编写 → 生成 → 审核 → 迭代。生成资源就像"编译"，人工审核就像"找 bug"。可反复优化直到满意。

🎬 完整工作流

像写代码一样：编写 → 生成 → 审核 → 迭代

1

📝 编写剧本

用 Markdown 写剧本，任意格式，完全自由。在 Cursor AI 中输入"根据剧本生成项目"，AI 自动提取主体、场景，拆分成 5秒/10秒 的分镜单元。

2

🤖 生成项目结构

AI 自动生成完整项目结构：提取主体保存到 `subjects/`，提取场景保存到 `scenes/`，拆分分镜保存到 `storyboards/`，生成首帧描述保存到 `first-frames/`。

3

🖼️ 生成图片资源

批量生成主体图片、场景图片和首帧图片。支持图生图合成，将主体和场景合成为首帧图片，确保角色外观一致。

4

🎬 生成视频片段

批量生成视频片段。支持文生视频、图生视频和首尾帧生视频。基于首帧生成，质量更稳定，可控性更强。

5

🎞️ 合成最终视频

使用 FFmpeg 将所有视频片段按顺序合成为最终视频。自动处理缺失片段，输出到 `output/final.mp4`。

📋 完整使用流程

1

安装扩展

选择上方的一键安装或手动安装方式完成扩展安装。

// 方式一：一键安装（推荐新手，特别是国内用户） // 下载并运行 install-vscode-extensions.bat // 会自动安装 VibeVideo + Qwen Code Companion（国内用户友好） // 方式二：手动安装（专业用户 / Cursor 用户） // VS Code Marketplace marketplace.visualstudio.com/items?itemName=fastpen.vibevideo
2

初始化项目

有两种方式可以初始化项目：

⚠️ 使用一键安装版本的用户请注意：

如果您使用一键安装版本，需要先启动 Qwen Code Companion（预览版本需要手动启动）：

Ctrl+Shift+P（Mac: Cmd+Shift+P） → "Qwen Code: Run"

启动后，再继续下面的初始化步骤。

方式一：命令面板
Ctrl+Shift+P → "Vibe Video: Initialize Project"
方式二：视图面板（推荐）
打开 View: "vibevideo" 点击 "初始化项目" 按钮
3

编写剧本

编辑 `Script.md`，写下您的视频脚本。

🤖 AI 编程助手用户提示：

如果您使用 Cursor、Qwen Code Companion 或其他 AI 编程助手，可以在 AI Chat 中直接输入以下命令，AI 会自动分析剧本并生成完整项目结构：

"根据剧本.md 生成项目"

✨ AI 会自动提取主体、场景，拆分成 5秒/10秒 的分镜单元，并生成完整的项目结构。

4

配置 API

配置视频 AI 服务（推荐通义万相）：

Ctrl+, → 搜索 "vibevideo" → 选择 Provider（通义万相） → 输入 DashScope API Key
5

生成资源

使用侧边栏资源视图或命令批量生成：

// 批量生成命令 "Vibe Video: Generate All Subjects" // 生成主体 "Vibe Video: Generate All Scenes" // 生成场景 "Vibe Video: Generate First Frames" // 生成首帧 "Vibe Video: Generate All Videos" // 生成视频 "Vibe Video: Compose Video" // 合成视频
