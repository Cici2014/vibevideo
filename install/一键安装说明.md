# VSCode 扩展一键安装说明

本目录包含一键安装脚本，用于自动安装 VibeVideo 和 Qwen Code Companion 扩展。

## 📦 包含的脚本

### Windows
1. **install-vscode-extensions.bat** - Windows 批处理脚本（适用于所有 Windows 用户）
2. **install-vscode-extensions.ps1** - PowerShell 脚本（功能更强大，推荐使用）

### macOS / Linux
3. **install-vscode-extensions.sh** - Shell 脚本（支持 macOS 和 Linux）

## 🚀 使用方法

### Windows 用户

#### 方法一：使用批处理脚本（推荐新手）

1. **双击运行** `install-vscode-extensions.bat`
2. 如果系统提示，选择"以管理员身份运行"
3. 等待脚本自动安装扩展
4. 完成后重启 VS Code

#### 方法二：使用 PowerShell 脚本（推荐）

1. **右键点击** `install-vscode-extensions.ps1`
2. 选择"使用 PowerShell 运行"
3. 如果出现执行策略限制，请按照提示操作：
   ```powershell
   # 临时允许执行（仅本次会话）
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   ```
4. 等待脚本自动安装扩展
5. 完成后重启 VS Code

### macOS / Linux 用户

1. **打开终端**（Terminal），进入 `install` 文件夹
2. **添加执行权限**：
   ```bash
   chmod +x install-vscode-extensions.sh
   ```
3. **运行脚本**：
   ```bash
   ./install-vscode-extensions.sh
   ```
4. 等待脚本自动安装扩展
5. 完成后重启 VS Code

## ⚙️ 前置要求

### 必须安装 VS Code

如果您的电脑还没有安装 VS Code：

#### Windows 用户

1. **下载 VS Code**
   - 访问：https://code.visualstudio.com/
   - 点击"Download for Windows"按钮

2. **安装 VS Code**
   - 运行下载的安装程序
   - **重要**：在安装选项中，务必勾选以下选项：
     - ✅ **"添加到 PATH"**（Add to PATH）- 这个选项必须勾选！
     - ✅ **"创建桌面快捷方式"**（Create desktop shortcut）- 可选但推荐
   - 点击"安装"并等待完成

3. **验证安装**
   - 按 `Win + R` 打开运行对话框
   - 输入 `cmd` 并按回车
   - 在命令提示符中输入：`code --version`
   - 如果显示版本号，说明安装成功
   - 如果提示"找不到命令"，说明未正确添加到 PATH，请重新安装 VS Code

#### macOS 用户

1. **下载 VS Code**
   - 访问：https://code.visualstudio.com/
   - 点击"Download for Mac"按钮

2. **安装 VS Code**
   - 下载完成后，打开 `.dmg` 文件
   - 将 VS Code 拖拽到 Applications 文件夹

3. **添加命令行工具到 PATH**
   - 打开 VS Code
   - 按 `Cmd + Shift + P` 打开命令面板
   - 输入并选择：`Shell Command: Install code command in PATH`
   - 这将允许在终端中使用 `code` 命令

4. **验证安装**
   - 打开终端（Terminal）
   - 输入：`code --version`
   - 如果显示版本号，说明安装成功

#### Linux 用户

1. **下载 VS Code**
   - 访问：https://code.visualstudio.com/
   - 根据您的发行版选择对应的安装包（.deb 或 .rpm）

2. **安装 VS Code**

   **Debian/Ubuntu:**
   ```bash
   sudo dpkg -i code_*.deb
   sudo apt-get install -f
   ```

   **Fedora/RHEL:**
   ```bash
   sudo rpm -ivh code-*.rpm
   ```

3. **验证安装**
   - 打开终端
   - 输入：`code --version`
   - 如果显示版本号，说明安装成功
   - 如果提示"找不到命令"，请检查 PATH 设置或重新安装

## ❓ 常见问题

### Q1: 脚本提示"未检测到 VS Code"

**原因**: VS Code 未安装或未添加到系统 PATH。

**解决方法**:

**Windows:**
1. 确认已安装 VS Code
2. 重新安装 VS Code，确保勾选"添加到 PATH"选项
3. 或者手动将 VS Code 安装目录添加到系统 PATH

**macOS:**
1. 确认已安装 VS Code
2. 打开 VS Code，按 `Cmd+Shift+P`，输入 `Shell Command: Install code command in PATH`
3. 重启终端后再次运行脚本

**Linux:**
1. 确认已安装 VS Code
2. 检查 `code` 命令是否在 PATH 中：`which code`
3. 如果不在，手动添加到 PATH 或重新安装 VS Code

### Q2: 扩展安装失败

**可能原因**:
- 网络连接问题
- 扩展ID不正确
- VS Code 未正确安装

**解决方法**:
1. 检查网络连接
2. 手动在 VS Code 扩展市场搜索并安装：
   - 打开 VS Code
   - 按 `Ctrl+Shift+X` (Windows/Linux) 或 `Cmd+Shift+X` (macOS) 打开扩展市场
   - 搜索 "VibeVideo" 和 "Qwen Code Companion"
   - 点击安装按钮

### Q3: PowerShell 脚本无法运行

**错误**: "无法加载文件...因为在此系统上禁止运行脚本"

**解决方法**:
```powershell
# 方法1: 临时允许执行（推荐）
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

# 方法2: 或者使用批处理脚本
# 直接运行 install-vscode-extensions.bat
```

### Q4: macOS/Linux 脚本无法运行

**错误**: "Permission denied" 或 "无法执行脚本"

**解决方法**:
```bash
# 给脚本添加执行权限
chmod +x install-vscode-extensions.sh

# 然后再运行
./install-vscode-extensions.sh
```

### Q5: 安装后扩展不显示

**解决方法**:
1. 重启 VS Code
2. 在扩展面板中查看已安装的扩展：
   - Windows/Linux: `Ctrl+Shift+X`
   - macOS: `Cmd+Shift+X`
3. 如果仍未显示，尝试重新安装扩展
