## 🎯 实现的功能

### 核心问题
**解决角色一致性问题**：
```
问题：纯文生图会导致同一角色在不同场景外观不一致
解决：预先生成固定角色图，然后合成到场景中
```

### 完整工作流
```
1. 定义主体 → subjects/猪大哥.md（详细描述）
2. 生成主体图 → Generate All Subjects → 猪大哥.png
3. 编写分镜 → storyboards/01.md（引用主体）
4. 合成初始帧 → Compose All First Frames → 将主体放入场景
5. 生成视频 → Generate All Videos → 角色完全一致！
```

### 关键技术
- ✅ Base64 编码本地图片（解决 API 需要 URL 的问题）
- ✅ 多图合成 API（qwen-image-edit-plus）
- ✅ 智能提示词构建（主体 + 场景 + 构图）
- ✅ 自动更新 Markdown（添加首帧路径）

## 🚀 如何测试

### 1. 重启扩展
```
按 F5 启动调试
```

### 2. 初始化项目
```
在新窗口打开文件夹
Ctrl+Shift+P → "Vibe Video: Initialize Project"
```

### 3. 检查 subjects 目录
```
应该看到：
- subjects/README.md
- subjects/示例主体.md
```

### 4. 创建角色
在 `subjects/` 创建 `猪大哥.md`：
```markdown
# 猪大哥

一只可爱的粉色小猪，戴着红色帽子，穿蓝色背心。
3D卡通风格，圆润的体型，大大的眼睛，友善的表情。
站立姿势，全身照，白色背景。
```

### 5. 生成主体图（需要 API Key）
```
Ctrl+Shift+P → "Vibe Video: Generate All Subjects"
```

### 6. 编写分镜（引用主体）
使用 Cursor AI：
```
@剧本.md 生成分镜脚本，使用 subjects/ 中的角色
```

或手动创建 `storyboards/01-opening.md`：
```markdown
# 01-开场

- **主体**: 猪大哥, 猪二哥
- **场景**: 草地
- **构图**: 并排站立

两只小猪开心地站在草地上...
```

### 7. 合成初始帧
```
Ctrl+Shift+P → "Vibe Video: Compose All First Frames"
```

### 8. 查看结果
```
assets/first-frames/01-opening.png
分镜 Markdown 自动更新，添加首帧路径
```

### 2. 图片大小限制
```

建议主体图不超过 2MB
```

```
提示词质量很重要
```
