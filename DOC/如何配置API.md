### 1️⃣ 打开设置
```
按 Ctrl+,
```

### 2️⃣ 搜索并配置
```
在搜索框输入: vibevideo
```

会看到 5 个配置项，填入 2 个关键信息即可：
- ✅ **Tongyi: Access Key Id**
- ✅ **Tongyi: Access Key Secret**

**就这么简单！** 🎉

## 🔑 获取 Access Key

### 步骤 1：打开阿里云控制台
点击这个链接：
```
https://ram.console.aliyun.com/manage/ak
```

或运行命令：
```
Ctrl+Shift+P → "Vibe Video: Configure Video AI"
→ 点击"查看获取指南"
```

### 步骤 2：创建 AccessKey
1. 登录您的阿里云账号
2. 点击 **"创建 AccessKey"** 按钮
3. 完成手机验证
4. **复制 AccessKey ID**（以 `LTAI` 开头）
5. **复制 AccessKey Secret**（⚠️ 只显示一次，请立即复制！）

### 步骤 3：粘贴到设置
1. 回到 VS Code
2. 按 `Ctrl+,` 打开设置
3. 搜索 `vibevideo`
4. 粘贴 **Access Key ID**
5. 粘贴 **Access Key Secret**
6. 完成！✅

## 🔒 安全提示

### 敏感信息保护

✅ **推荐做法**：
- 配置在"用户设置"中（全局）
- 不会被提交到 Git
- 所有项目共享

⚠️ **避免**：
- 不要配置在"工作区设置"中
- 否则会保存到项目的 `.vscode/settings.json`
- 可能被误提交到 Git

### 如何区分？

在设置页面右上角：
```
[用户] [工作区] [文件夹]
 ↑
选择"用户"标签（推荐）
```

## 💡 常见问题

### Q: 配置后在哪里可以看到？
**A**: 
```
C:\Users\YourName\AppData\Roaming\Code\User\settings.json
```
或按 `Ctrl+Shift+P` → `Preferences: Open User Settings (JSON)`

### Q: 如何修改配置？
**A**: 
直接在设置中修改，自动保存。或运行 `Show Current Config` → 点击"打开设置"。

### Q: Access Key Secret 安全吗？
**A**: 
存储在本地配置文件中（明文），建议：
- 不要分享 settings.json
- 不要截图包含配置的页面
- 定期更换 Access Key

### Q: 可以用环境变量吗？
**A**: 
当前版本不支持，但是一个好主意！可以在未来版本添加。
