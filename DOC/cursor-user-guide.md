# Cursor 用户如何使用 VibeVideo：像写代码一样制作视频

> **让 AI 视频制作变得像编程一样简单**

## 前言

作为一名 Cursor 用户，你已经习惯了用 AI 辅助编程：写代码、调试、重构，一切都变得高效而自然。那么，有没有想过用同样的方式制作视频呢？

**VibeVideo** 正是这样一个工具：它让你能够**像写代码一样制作视频**——用 Markdown 写剧本，用 Cursor AI 生成项目结构，批量生成视频片段，一键合成。整个工作流就如同软件开发一样：**编写 → 生成 → 审核 → 迭代**。

本文将为你详细介绍，作为 Cursor 用户，如何充分利用 VibeVideo 和 Cursor AI 的强大组合，高效制作专业视频。

## 快速开始：5 分钟上手

### 第一步：安装 VibeVideo 扩展

1. 打开 Cursor
2. 按 `Ctrl+Shift+X` 打开扩展市场（Cursor 使用 Open VSX 市场）
3. 搜索 `VibeVideo` 并安装
4. 重启 Cursor

### 第二步：配置 API Key（一次性）

VibeVideo 支持多个 AI 服务商，推荐使用**通义万相**（国内服务，中文支持优秀）：

1. **获取 API Key**
   - 访问 [DashScope 控制台](https://bailian.console.aliyun.com/)
   - 注册/登录后，创建 API Key

2. **配置到 Cursor**
   - 按 `Ctrl+,` 打开设置
   - 搜索 `vibevideo`
   - 设置 Provider 为 `tongyi-wanxiang`
   - 填入你的 DashScope API Key

或者使用命令：
```
Ctrl+Shift+P → "Vibe Video: Configure Video AI"
```

### 第三步：创建你的第一个项目

1. **创建项目文件夹**并打开
   ```
   File → Open Folder → 选择你的项目文件夹
   ```

2. **初始化项目**
   ```
   Ctrl+Shift+P → "Vibe Video: Initialize Project"
   ```

   这会自动创建标准化的项目结构：
   ```
   MyVideoProject/
   ├── 剧本.md              # 你的视频剧本
   ├── subjects/            # 主体/角色库
   ├── scenes/              # 场景库
   ├── storyboards/         # 分镜脚本
   ├── first-frames/        # 首帧图片
   ├── video-clip/          # 生成的视频片段
   ├── output/              # 最终视频
   ├── .cursorrules         # Cursor AI 规则（自动生成）
   └── ...
   ```

## 核心工作流：用 Cursor AI 生成项目

VibeVideo 最强大的特性之一，就是与 Cursor AI 的深度集成。初始化项目后，会自动生成 `.cursorrules` 文件，让 Cursor AI 理解项目结构和工作流。

### 📝 第一步：编写剧本

编辑 `剧本.md`，用 Markdown 写下你的视频想法：

```markdown
# 我的产品宣传视频

## 场景 1：开场

主角走在繁华的城市街道上，微笑着向镜头挥手。阳光明媚，街道两旁是现代建筑。

## 场景 2：产品展示

主角走进咖啡店，拿出我们的产品，镜头聚焦在产品上。产品外观精美，设计现代。

## 场景 3：使用场景

主角使用产品，享受美好时光。画面温馨，氛围轻松。
```

**💡 提示**：可以借助 Cursor AI 帮你完善剧本，比如：
```
帮我优化这个剧本，让它更生动有趣，适合产品宣传
```

### 🤖 第二步：用 Cursor AI 生成项目结构

这是最酷的部分！在 Cursor AI Chat 中输入：

```
根据剧本.md 生成完整的项目结构，包括：
1. 提取所有主体（角色），保存到 subjects/ 目录
2. 提取所有场景，保存到 scenes/ 目录
3. 将场景拆分成 5秒或10秒的分镜
4. 为每个分镜生成详细脚本，保存到 storyboards/ 目录
5. 为每个分镜生成首帧描述，保存到 first-frames/ 目录
```

Cursor AI 会自动：
- ✅ 分析剧本内容
- ✅ 提取主体和场景
- ✅ 生成标准化的 Markdown 文件
- ✅ 创建完整的分镜结构

**为什么这么智能？**

因为 VibeVideo 已经生成了 `.cursorrules` 文件，其中包含了：
- 项目结构说明
- 分镜脚本格式规范
- 提示词编写指南
- 工作流程说明

Cursor AI 读取这些规则后，就像理解你的代码库规范一样，能够生成符合要求的文件结构。

### 📁 生成的项目结构示例

```
MyVideoProject/
├── subjects/
│   └── 主角.md          # AI 生成的角色描述
├── scenes/
│   ├── 城市街道.md      # AI 生成的场景描述
│   └── 咖啡店.md
├── storyboards/
│   ├── 01-opening.md    # AI 生成的分镜脚本（5秒或10秒）
│   ├── 02-product.md
│   └── 03-usage.md
└── first-frames/
    ├── 01-opening-first-frame.md  # AI 生成的首帧描述
    ├── 02-product-first-frame.md
    └── 03-usage-first-frame.md
```

### 🎨 第三步：生成图片资源

在左侧的 **Vibe Video** 侧边栏中，你可以看到所有资源。右键点击可以：

1. **生成主体图片**
   - 右键 `📦 主体` → `生成所有主体`
   - 或者命令：`Vibe Video: Generate All Subjects`

2. **生成场景图片**
   - 右键 `🎬 场景` → `生成所有场景`
   - 或者命令：`Vibe Video: Generate All Scenes`

3. **生成首帧图片**
   - 右键 `🖼️ 首帧` → `生成所有首帧`
   - 或者命令：`Vibe Video: Generate First Frames`

**💡 提示**：生成过程会调用 AI API，可能需要一些时间。你可以在输出面板查看进度。

### 🎬 第四步：生成视频片段

所有首帧生成完成后，就可以生成视频了：

- 右键 `🎬 分镜` → `生成所有视频`
- 或者命令：`Vibe Video: Generate All Videos`

每个分镜会生成一个视频片段（5秒或10秒），保存到 `video-clip/` 目录。

### 🎞️ 第五步：合成最终视频

所有视频片段生成完成后：

- 右键 `🎥 视频片段` → `视频合成`
- 或者命令：`Vibe Video: Compose Video`

最终视频会保存到 `output/` 目录。

## 进阶技巧：充分利用 Cursor AI

### 💡 技巧 1：用 AI 优化提示词

生成的项目结构中，每个文件都包含描述文本。你可以用 Cursor AI 优化这些提示词：

1. 打开 `subjects/主角.md`
2. 选中描述文本
3. 在 Cursor AI Chat 中问：
   ```
   这个角色描述能否更详细一些？特别是外观特征
   ```
4. AI 会给出优化建议或直接修改

### 💡 技巧 2：批量修改分镜脚本

如果需要修改所有分镜的某个共同点：

1. 用 Cursor AI Chat：
   ```
   帮我把所有分镜脚本中的"城市街道"改为"现代都市"
   ```
2. AI 会自动批量修改所有相关文件

### 💡 技巧 3：参考图驱动工作流

如果你有参考图片（比如客户提供的产品照片）：

1. **保存参考图**
   - 侧边栏 `📸 参考图` → 点击 `+` 按钮
   - 或者命令：`Vibe Video: 添加参考图`

2. **在 Markdown 中引用**
   ```markdown
   # 主角
   
   - **参考图**: ref-img/product.jpg
   
   外观描述...
   ```
   
3. **让 Cursor AI 基于参考图生成描述**
   ```
   根据 ref-img/product.jpg 这个参考图，帮我完善主体描述
   ```

生成时会自动使用参考图，确保结果与参考图保持一致。

### 💡 技巧 4：多角度首帧生成（高级）

如果你已经生成了首帧，想要快速生成多个角度的候选图，可以使用 RunningHub 工作流功能：

1. **配置 RunningHub**（详见 [RunningHub 工作流创建指南](runninghub-workflow-guide.md)）
2. **右键首帧图片** → 选择角度（俯视、仰视、广角、特写等）
3. 系统会调用 RunningHub 工作流，基于原图生成新角度的图片

## 实际案例：5 分钟制作一个产品宣传视频

让我们用一个完整的例子，看看如何用 Cursor + VibeVideo 快速制作视频：

### 场景描述

假设你要为一款智能手环制作 30 秒的宣传视频。

### 步骤详解

#### 1. 编写剧本（1 分钟）

在 Cursor 中打开 `剧本.md`，写下：

```markdown
# 智能手环宣传视频

## 场景 1：健康生活（10秒）

一位年轻人在清晨的公园里跑步，佩戴智能手环，记录运动数据。阳光透过树叶洒下，画面充满活力。

## 场景 2：产品特写（10秒）

智能手环特写镜头，展示屏幕上的各项数据：心率、步数、卡路里。产品外观精美，科技感十足。

## 场景 3：夜晚使用（10秒）

主角在夜晚查看手环，屏幕亮起，显示睡眠监测数据。画面温馨，科技融入生活。
```

#### 2. 用 Cursor AI 生成项目（1 分钟）

在 Cursor AI Chat 中：

```
根据剧本.md 生成项目，注意：
- 主角是健康的年轻人
- 产品是智能手环，黑色，方形屏幕
- 三个场景分别是：公园、产品特写、夜晚卧室
- 每个场景分成一个 10秒 分镜
```

Cursor AI 会自动生成所有必要的文件。

#### 3. 生成资源（2 分钟）

在 Vibe Video 侧边栏中：
- 生成主体（主角、手环）
- 生成场景（公园、卧室）
- 生成首帧
- 生成视频

#### 4. 审核和调整（1 分钟）

如果某个视频片段不满意：
- 修改对应的分镜脚本或首帧描述
- 重新生成单个视频
- 继续迭代直到满意

#### 5. 合成最终视频（30 秒）

一键合成，完成！

**总耗时：约 5-10 分钟**（取决于 AI API 响应速度）

## 最佳实践

### ✅ DO（推荐做法）

1. **充分利用 Cursor AI**
   - 让 AI 帮你写剧本、优化描述、批量修改
   - 用 AI 理解项目结构，生成规范文件

2. **迭代式工作**
   - 先快速生成一个版本
   - 逐个审核和优化
   - 不满意就重新生成

3. **使用参考图**
   - 特别是产品展示，参考图能确保一致性
   - 参考图放在 `ref-img/` 目录，在 Markdown 中引用

4. **主体库管理**
   - 建立角色库，确保同一角色在不同分镜中外观一致
   - 主体描述要详细，包括服装、特征等

### ❌ DON'T（避免的做法）

1. **不要一次性生成所有内容**
   - 建议分阶段：先主体和场景，再首帧，最后视频
   - 每一步都审核，避免浪费 API 调用

2. **不要忽略 `.cursorrules`**
   - 这个文件让 Cursor AI 理解项目
   - 如果修改了项目结构，记得更新规则

3. **不要写太长的分镜脚本**
   - 每个分镜 5秒或10秒，描述要精炼
   - 重点是第一帧画面和关键动作

## 常见问题 FAQ

### Q1: 为什么分镜时长只能是 5秒或10秒？

**A**: 这是设计上的权衡：
- ✅ 固定时长便于批量处理
- ✅ 简化工作流，减少配置
- ✅ 统一时长便于估算成本

如果确实需要其他时长，可以生成后手动裁剪。

### Q2: 可以用自己的图片吗？

**A**: 可以！使用参考图功能：
1. 将图片保存到 `ref-img/` 目录
2. 在 Markdown 中引用：`- **参考图**: ref-img/your-image.jpg`
3. 生成时会基于参考图

### Q3: 生成的视频质量如何？

**A**: 取决于使用的 AI Provider：
- **通义万相**（推荐）：质量稳定，中文支持好
- **OpenAI Sora**：质量高，但有使用限制
- 其他 Provider：功能完整，但可能需要测试

建议先用通义万相测试，满意后再考虑其他方案。

### Q4: Cursor AI 生成的脚本格式不对怎么办？

**A**: 
1. 检查 `.cursorrules` 文件是否存在
2. 在 Cursor AI Chat 中明确说明格式要求
3. 手动修改一个示例文件，让 AI 学习

### Q5: 如何批量修改多个分镜？

**A**: 使用 Cursor AI Chat：
```
帮我把所有分镜脚本中的"主角"改为"年轻女性"
```

AI 会自动批量修改所有相关文件。
