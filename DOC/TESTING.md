# Vibe Video 测试指南

## 🧪 如何测试当前版本

### 准备工作

1. **启动扩展开发主机**
   ```
   按 F5 键
   或
   运行 → 启动调试
   ```

2. **在新窗口中创建测试项目**
   ```
   新窗口会自动打开
   文件 → 打开文件夹
   创建一个新文件夹（如：TestVideoProject）
   ```

---

## 测试场景 1：项目初始化

### 步骤
1. 在新窗口中，按 `Ctrl+Shift+P`
2. 输入 `Vibe Video: Initialize Project`
3. 按回车执行

### 预期结果
- ✅ 显示进度通知："正在初始化项目..."
- ✅ 自动创建文件夹结构：
  ```
  TestVideoProject/
  ├── 剧本.md
  ├── .vv-project.json
  ├── .cursorrules
  ├── .clinerules
  ├── .gitignore
  ├── .vv-context/
  ├── storyboards/
  ├── assets/
  │   ├── subjects/
  │   ├── first-frames/
  │   ├── clips/
  │   ├── audio/
  │   └── references/
  └── output/
  ```
- ✅ 自动打开 `剧本.md` 文件
- ✅ 显示成功消息

### 验证
- 打开 `.cursorrules`，检查内容是否完整
- 打开 `.vv-context/README.md`，查看 AI 上下文说明
- 查看文件资源管理器，确认所有文件夹已创建

---

## 测试场景 2：侧边栏视图

### 步骤
1. 点击左侧活动栏的 Vibe Video 图标（📹）
2. 查看"项目资源"视图

### 预期结果
- ✅ 显示 4 个主要节点：
  - 📝 分镜脚本
  - 🖼️ 初始帧
  - 🎬 视频片段
  - 📊 项目信息
- ✅ 展开"分镜脚本"：显示"暂无分镜脚本"
- ✅ 展开"项目信息"：显示统计数据（全为 0）

---

## 测试场景 3：生成分镜（需要 Cursor AI）

### 步骤
1. 编辑 `剧本.md`，写入一段剧本
   ```markdown
   # 咖啡馆的清晨
   
   阳光透过玻璃窗照进咖啡馆。
   店主正在准备第一杯咖啡。
   客人陆续进入，开始美好的一天。
   ```

2. 打开 Cursor AI Chat（`Ctrl+L`）

3. 输入提示词：
   ```
   根据剧本.md 生成分镜脚本
   ```

4. AI 应该生成多个 Markdown 文件到 `storyboards/` 目录

### 预期结果
- ✅ AI 理解 `.cursorrules` 中的指令
- ✅ 生成 Markdown 格式的分镜文件（不是 JSON）
- ✅ 每个文件包含：
  - `# 标题`
  - 视觉描述
  - （可选）时长、首帧等元数据
- ✅ 侧边栏自动更新，显示新生成的分镜

### 示例生成的分镜
**文件**：`storyboards/01-morning-light.md`
```markdown
# 清晨的阳光

- **时长**: 5秒

咖啡馆的玻璃窗，金色的阳光从外面照进来，
在木质地板上投下温暖的光斑。
镜头从窗外缓慢推进，透过玻璃看向室内。
光线柔和，色调温暖，充满希望和新的开始的感觉。
```

## 测试场景 4：质量检查

### 步骤
1. 确保已生成一些分镜脚本
2. 按 `Ctrl+Shift+P`
3. 输入 `Vibe Video: Check Storyboards Quality`
4. 按回车执行

### 预期结果
- ✅ 显示输出通道（Output Channel）
- ✅ 显示质量检查结果：
  ```
  分镜质量检查结果：
  - 优秀: 2
  - 良好: 1
  - 可用: 0
  - 需要改进: 0
  
  ✅ 01-morning-light: 优秀
  ✓ 02-coffee-making: 良好
  ```
- ✅ 显示通知消息
- ✅ 侧边栏中的分镜显示质量图标

---

## 测试场景 5：侧边栏交互

### 步骤
1. 在侧边栏中点击一个分镜脚本（如 `01-morning-light.md`）
2. 文件应该在编辑器中打开
3. Hover 鼠标到分镜项上，查看提示信息

### 预期结果
- ✅ 点击打开 Markdown 文件
- ✅ 可以直接编辑
- ✅ 侧边栏显示正确的图标：
  - ✅ = 优秀
  - ⚠️ = 可用但有建议
  - 💡 = 需要改进
  - 🖼️ = 有首帧

---

## 测试场景 6：项目统计

### 步骤
1. 确保已生成一些分镜
2. 按 `Ctrl+Shift+P`
3. 输入 `Vibe Video: Show Project Stats`
4. 按回车执行

### 预期结果
- ✅ 显示统计信息弹窗：
  ```
  项目统计：
  - 分镜数量: 3
  - 总时长: 15 秒 (0分15秒)
  ```

## 测试场景 7：重新初始化

### 步骤
1. 在已初始化的项目中
2. 再次运行 `Vibe Video: Initialize Project`

### 预期结果
- ✅ 显示警告："该项目已经初始化过了，是否重新初始化？"
- ✅ 点击"否"：取消操作
- ✅ 点击"是"：重新初始化

## 🐛 已知问题测试

### 边界情况

#### 测试 1：空工作区
1. 不打开任何文件夹
2. 尝试运行命令

预期：显示错误："请先打开一个工作区文件夹！"

#### 测试 2：非 VV 项目
1. 打开一个普通文件夹（未初始化）
2. 运行 `Check Storyboards Quality`

预期：显示警告："当前不是 Vibe Video 项目，请先初始化项目。"

#### 测试 3：空分镜目录
1. 初始化项目
2. 不生成任何分镜
3. 运行质量检查

预期：显示提示："暂无分镜脚本。提示：使用 Cursor AI 生成分镜脚本！"

#### 测试 4：错误的 Markdown 文件
1. 手动创建一个空的 Markdown 文件到 `storyboards/`
2. 查看侧边栏

预期：解析器应该容错，不崩溃
