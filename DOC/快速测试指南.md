# Vibe Video 快速测试指南

## 🚀 第一步：启动调试

### 方法 1：使用快捷键（推荐）
```
按 F5
```

### 方法 2：使用菜单
```
运行 → 启动调试
或
Run → Start Debugging
```

### 会发生什么？
- VS Code 会编译代码
- 打开一个新的 **扩展开发主机** 窗口（标题栏显示"[扩展开发主机]"）
- 在这个新窗口中，您的扩展已被加载

---

## 📁 第二步：创建测试项目

### 在新窗口中：

1. **打开一个文件夹**
   ```
   文件 → 打开文件夹
   或按 Ctrl+K Ctrl+O
   ```

2. **创建新文件夹**（或选择现有空文件夹）
   ```
   例如：C:\Users\YourName\Desktop\TestVideo
   ```

3. **选择该文件夹并打开**

### 1. 打开命令面板

```

```
输入: Vibe Video: Initialize Project

```

### 3. 观察结果

#### 应该看到：
1. **进度通知**
   ```
   Vibe Video

## 🤖 第五步：使用 Cursor AI 生成分镜（关键！）

### 1. 编辑剧本

打开 `剧本.md`，修改或替换为您自己的内容，例如：

```markdown
# 产品宣传视频：智能手表

## 概述
展示我们的新款智能手表，强调科技感和生活方式。

## 场景

### 开场
清晨，年轻人醒来，看到床头柜上的智能手表。

### 功能展示
手表的各种功能特写：运动追踪、心率监测、消息通知。

### 生活场景
佩戴手表的日常场景：晨跑、工作、社交。

### 结尾
Logo 展示，slogan。
```

### 2. 打开 Cursor AI Chat

```
按 Ctrl+L（或点击右上角的 Cursor 图标）
```

### 3. 输入提示词

```
根据剧本.md 生成分镜脚本
```

### 4. AI 会做什么？

AI 会：
1. 读取 `剧本.md` 的内容
2. 读取 `.cursorrules`（理解项目结构和要求）
3. 自动生成多个 Markdown 文件到 `storyboards/` 目录

例如，AI 可能生成：
- `storyboards/01-morning-wake.md`
- `storyboards/02-watch-closeup.md`
- `storyboards/03-exercise.md`
- 等等...

### 5. 查看生成的分镜

在文件资源管理器中打开 `storyboards/` 文件夹，应该看到生成的 Markdown 文件。

**示例内容**（`01-morning-wake.md`）：
```markdown
# 清晨醒来

- **时长**: 5秒

清晨的卧室，柔和的晨光从窗帘缝隙透进来。
床头柜上的智能手表显示时间 06:30，屏幕微微发光。
镜头从远处缓慢推进到手表特写。
光线温暖，色调柔和，充满宁静和新的一天开始的感觉。
```

### 6. 侧边栏自动更新

点击左侧的 Vibe Video 图标，侧边栏应该显示：

```
📝 分镜脚本 (3)
├── ✅ 01-morning-wake.md (优秀 🖼️)
├── ✅ 02-watch-closeup.md
└── ⚠️ 03-exercise.md (描述较短)
```

## ❓ 常见问题

### Q: 按 F5 没反应？
**A**: 确保您在原始项目窗口（vibevideo 项目）中按 F5，不是在扩展开发主机窗口中。

### Q: 看不到 Vibe Video 图标？
**A**: 
1. 检查编译是否成功（运行 `npm run compile`）
2. 重新按 F5
3. 在新窗口中查找左侧活动栏

### Q: Cursor AI 没有生成 Markdown？
**A**: 
1. 检查 .cursorrules 是否正确生成
2. 尝试更明确的提示词："根据剧本.md 生成 Markdown 格式的分镜脚本，保存到 storyboards/ 目录"
3. 确保 Cursor 能访问工作区文件

### Q: 侧边栏显示"暂无分镜脚本"？
**A**: 
1. 检查 `storyboards/` 目录是否有 .md 文件
2. 点击刷新按钮
3. 查看开发者工具（帮助 → 切换开发人员工具）检查是否有错误
