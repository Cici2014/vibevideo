## 简介

### 什么是 Vibe Video？

Vibe Video 是一个 VS Code 扩展，让您能够**像写代码一样制作视频**：

- 📝 **用 Markdown 写剧本**：像写文档一样编写视频脚本
- 🤖 **AI 生成分镜**：使用 Cursor AI 等工具自动生成完整项目结构
- 🎬 **批量生成视频**：一键生成所有视频片段
- ✅ **迭代优化**：像调试代码一样反复优化视频内容

### 核心理念

Vibe Video 的工作流就像写代码：**编写 → 生成 → 审核 → 迭代**

```
编写剧本 → AI生成项目结构 → 生成图片资源 → 生成视频片段 → 完成
     ↑                                                          ↓
     └─────────────────── 审核/迭代 ←──────────────────────────┘
```

整个过程可以反复迭代，直到满意为止。

## 安装与配置

### 1. 安装扩展

#### 方法 1：从 VS Code Marketplace 安装（推荐）

1. 打开 VS Code
2. 按 `Ctrl+Shift+X` 打开扩展市场
3. 搜索 `Vibe Video` 或 `vibevideo`
4. 点击 **安装**

#### 方法 2：从源码安装

1. 克隆仓库：
   ```bash
   git clone https://github.com/Cici2014/vibevideo.git
   ```
2. 进入目录：
   ```bash
   cd vibevideo
   ```
3. 安装依赖：
   ```bash
   npm install
   ```
4. 按 `F5` 启动调试模式

### 2. 配置 API Key

Vibe Video 需要配置 AI 服务商的 API Key 才能生成视频。

#### 支持的 Provider

| Provider | 状态 | 说明 |
|---------|------|------|
| **通义万相** | ✅ 生产就绪 | 国内服务，中文支持优秀，推荐使用 |
| **Replicate** | ⚠️ 测试阶段 | 国际服务，支持多种开源模型 |

#### 配置通义万相（推荐）

**步骤 1：获取 API Key**

1. 访问 [DashScope 控制台](https://bailian.console.aliyun.com/)
2. 登录/注册阿里云账号
3. 开通 DashScope 服务（通常有免费额度）
4. 在 **API Key 管理**页面创建 API Key
5. 复制 API Key（格式：`sk-xxxxx`）

**步骤 2：在 VS Code 中配置**

**方法 1：通过设置界面（推荐）**

1. 按 `Ctrl+,` 打开设置
2. 搜索 `vibevideo`
3. 找到 **Dashscope: Api Key**
4. 粘贴您的 API Key
5. 确保 **Provider** 选择为 `tongyi-wanxiang`

**方法 2：通过命令**

1. 按 `Ctrl+Shift+P` 打开命令面板
2. 输入 `Vibe Video: Configure Video AI`
3. 点击 **打开设置**
4. 填写 API Key

**方法 3：直接编辑 settings.json**

1. 按 `Ctrl+Shift+P` 打开命令面板
2. 输入 `Preferences: Open User Settings (JSON)`
3. 添加配置：
   ```json
   {
     "vibevideo.provider": "tongyi-wanxiang",
     "vibevideo.dashscope.apiKey": "sk-你的API密钥"
   }
   ```

#### 配置 Replicate（测试阶段）

1. 访问 [Replicate 官网](https://replicate.com/)
2. 注册/登录账号
3. 访问 [API Tokens 页面](https://replicate.com/account/api-tokens)
4. 创建 API Token
5. 在 VS Code 设置中：
   - 设置 `vibevideo.provider` 为 `replicate`
   - 设置 `vibevideo.replicate.apiKey` 为您的 Token

#### 验证配置

**方法 1：查看配置**

```
Ctrl+Shift+P → "Vibe Video: Show Current Config"
```

应该显示：
```
当前 Provider: tongyi-wanxiang
状态: ✓ 已配置
API Key: sk-xxxxx...
```

**方法 2：测试生成**

配置完成后，可以尝试生成一个首帧图片来验证配置是否正确。

## 快速开始

### 5 分钟快速上手

#### 步骤 1：创建项目文件夹

1. 在文件管理器中创建一个新文件夹（例如：`MyVideoProject`）
2. 在 VS Code 中打开这个文件夹：
   ```
   File → Open Folder → 选择 MyVideoProject
   ```

#### 步骤 2：初始化项目

**方法 1：使用命令**

1. 按 `Ctrl+Shift+P` 打开命令面板
2. 输入 `Vibe Video: Initialize Project`
3. 回车执行

**方法 2：使用侧边栏**

1. 在左侧活动栏找到 **Vibe Video** 图标（🎬）
2. 点击 **项目资源** 视图
3. 点击 **初始化项目** 按钮

初始化完成后，项目结构会自动创建，并打开 `剧本.md` 文件。

#### 步骤 3：编写剧本

编辑 `剧本.md`，写下您的视频脚本。例如：

```markdown
# 我的第一个视频

## 场景 1：开场

一个阳光明媚的早晨，主角走在城市街道上，微笑着向镜头挥手。

## 场景 2：展示

主角走进一家咖啡店，点了一杯咖啡，坐在窗边享受美好时光。

## 场景 3：结尾

主角走出咖啡店，向镜头挥手告别，画面淡出。
```

#### 步骤 4：使用 AI 生成项目结构

**使用 Cursor AI（推荐）**

1. 在 Cursor AI Chat 中输入：
   ```
   根据剧本.md 生成项目
   ```
2. AI 会自动执行以下步骤：
   - 提取主体（角色）
   - 提取场景
   - 拆分分镜（5秒/10秒）
   - 生成分镜脚本
   - 生成首帧描述

**使用其他 AI 工具**

- **Cline**：同样支持 `.clinerules` 文件
- **GitHub Copilot Chat**：可以手动提供上下文
- **Claude Code**：支持 `.claude-rules` 文件

#### 步骤 5：生成资源

**批量生成（推荐）**

1. 按 `Ctrl+Shift+P` 打开命令面板
2. 依次执行：
   - `Vibe Video: Generate All Subjects` - 生成所有主体图片
   - `Vibe Video: Generate All Scenes` - 生成所有场景图片
   - `Vibe Video: Generate First Frames` - 生成所有首帧图片
   - `Vibe Video: Generate All Videos` - 生成所有视频

**单个生成（右键菜单）**

在侧边栏资源视图中，右键点击任意资源，选择对应的生成命令。

#### 步骤 6：查看结果

生成的视频片段保存在 `video-clip/` 目录中，您可以在 VS Code 中直接预览。

## 完整工作流程

### 详细流程说明

#### 阶段 1：项目准备

**1.1 创建项目**

```bash
mkdir MyVideoProject
cd MyVideoProject
code .
```

**1.2 初始化项目**

```
Ctrl+Shift+P → "Vibe Video: Initialize Project"
```

这会创建以下结构：

```
MyVideoProject/
├── 剧本.md                   # 您的剧本
├── subjects/                 # 主体/角色目录
├── scenes/                   # 场景目录
├── storyboards/              # 分镜脚本目录
├── first-frames/             # 首帧目录
├── video-clip/               # 视频片段目录
├── ref-img/                  # 参考图目录（可选）
├── output/                   # 最终输出目录
├── .vv-context/              # AI 上下文文档
├── .cursorrules              # Cursor AI 规则
└── .vv-project.json          # 项目配置
```

**1.3 配置 API**

确保已配置好 API Key（见 [配置 API Key](#2-配置-api-key)）

#### 阶段 2：编写剧本

**2.1 编写剧本**

编辑 `剧本.md`，可以自由格式编写，例如：

```markdown
# 产品宣传视频

## 第一幕：问题引入

用户在使用传统产品时遇到的各种不便...

## 第二幕：产品展示

我们的产品如何解决这些问题...

## 第三幕：行动号召

立即购买，享受优惠...
```

**2.2 剧本编写技巧**

- ✅ **清晰的结构**：使用标题组织场景
- ✅ **详细的描述**：描述画面、动作、情绪
- ✅ **对话内容**：如果需要对话，直接写在剧本中
- ✅ **参考素材**：如果有参考图片，放在 `ref-img/` 目录

#### 阶段 3：AI 生成项目结构

**3.1 使用 Cursor AI**

在 Cursor AI Chat 中输入：

```
根据剧本.md 生成完整的项目结构，包括：
1. 提取所有主体（角色），保存到 subjects/ 目录
2. 提取所有场景，保存到 scenes/ 目录
3. 将场景拆分成 5秒或10秒的分镜
4. 为每个分镜生成详细脚本，保存到 storyboards/ 目录
5. 为每个分镜生成首帧描述，保存到 first-frames/ 目录
```

**3.2 AI 生成的内容**

AI 会自动生成：

- **主体文件**（`subjects/主角.md`）：
  ```markdown
  # 主角
  
  一个年轻的白领，穿着商务休闲装，面带微笑，充满活力。
  ```

- **场景文件**（`scenes/城市街道.md`）：
  ```markdown
  # 城市街道
  
  繁华的都市街道，车流如织，行人匆匆，阳光透过高楼洒下。
  ```

- **分镜脚本**（`storyboards/01-opening.md`）：
  ```markdown
  # 开场镜头
  
  - **时长**: 5秒
  - **主体**: 主角
  - **场景**: 城市街道
  - **参考图**: first-frames/01-opening-first-frame.png
  - **首帧**: first-frames/01-opening-first-frame.png
  
  镜头缓慢推进，展现城市街道的繁华景象，主角从远处走来，微笑着向镜头挥手。
  ```

- **首帧描述**（`first-frames/01-opening-first-frame.md`）：
  ```markdown
  # 01-opening 首帧
  
  城市街道的远景，主角站在街道中央，阳光洒在他身上，背景是现代化的高楼大厦。
  ```

**3.3 审核和调整**

生成后，检查并调整：
- 分镜时长是否正确（只能是 5秒 或 10秒）
- 主体和场景描述是否准确
- 分镜脚本是否完整
- 首帧描述是否清晰

#### 阶段 4：生成图片资源

**4.1 生成主体图片**

```
Ctrl+Shift+P → "Vibe Video: Generate All Subjects"
```

这会为每个主体生成一张图片（白色背景，便于后续合成）。

**4.2 生成场景图片**

```
Ctrl+Shift+P → "Vibe Video: Generate All Scenes"
```

这会为每个场景生成一张背景图片。

**4.3 生成首帧图片**

有两种方式：

**方式 1：直接生成（文生图）**

```
Ctrl+Shift+P → "Vibe Video: Generate First Frames"
```

**方式 2：合成生成（主体+场景）**

如果分镜脚本中指定了主体和场景，可以使用合成功能：

```
Ctrl+Shift+P → "Vibe Video: Compose All First Frames"
```

这会使用主体图片和场景图片合成首帧图片。

**4.4 审核图片**

- 检查主体外观是否一致
- 检查场景是否符合描述
- 检查首帧是否准确反映分镜内容
- 如果不满意，可以删除图片重新生成

#### 阶段 5：生成视频

**5.1 生成单个视频**

在侧边栏中，右键点击分镜脚本，选择 **生成视频**。

**5.2 批量生成视频**

```
Ctrl+Shift+P → "Vibe Video: Generate All Videos"
```

**5.3 使用首尾帧生成视频（高级）**

如果分镜脚本中指定了尾帧，可以使用首尾帧生成视频，实现更精确的控制：

```
Ctrl+Shift+P → "Vibe Video: Generate All Videos From First Last Frame"
```

**5.4 视频生成过程**

1. 系统读取分镜脚本
2. 加载首帧图片（或使用文本提示词）
3. 调用 AI API 生成视频
4. 视频保存到 `video-clip/` 目录
5. 在侧边栏显示生成状态

**5.5 审核视频**

- 播放生成的视频片段
- 检查画面是否符合预期
- 检查时长是否正确
- 检查动作是否流畅
- 如果不满意，删除视频重新生成

#### 阶段 6：合成最终视频（可选）

目前视频合成功能正在开发中，您可以：

1. 使用 ffmpeg 手动合成：
   ```bash
   ffmpeg -f concat -safe 0 -i filelist.txt -c copy output.mp4
   ```

2. 使用视频编辑软件（如 Premiere、Final Cut Pro）导入所有片段进行编辑

## 核心功能详解

### 1. 项目管理

#### 初始化项目

创建标准化的项目结构，包括：
- 目录结构
- AI 规则文件（`.cursorrules`、`.clinerules` 等）
- AI 上下文文档（`.vv-context/`）
- 示例文件

#### 项目统计

```
Ctrl+Shift+P → "Vibe Video: Show Project Stats"
```

显示：
- 主体数量
- 场景数量
- 分镜数量
- 已生成的首帧数量
- 已生成的视频数量
- 项目进度

#### 质量检查

```
Ctrl+Shift+P → "Vibe Video: Check Storyboards Quality"
```

检查：
- 分镜时长是否正确（只能是 5秒 或 10秒）
- 是否缺少必要字段
- 提示词质量
- 给出改进建议

### 2. 资源生成

#### 主体生成

**用途**：确保角色外观一致

**特点**：
- 白色背景，便于合成
- 可以复用，确保同一角色在不同分镜中外观一致

**生成方式**：
- 批量：`Vibe Video: Generate All Subjects`
- 单个：右键点击主体文件 → **生成主体**

#### 场景生成

**用途**：创建背景环境

**特点**：
- 可以复用，同一场景在不同分镜中使用
- 不包含角色，只包含环境

**生成方式**：
- 批量：`Vibe Video: Generate All Scenes`
- 单个：右键点击场景文件 → **生成场景**

#### 首帧生成

**用途**：定义视频的第一帧画面

**生成方式**：

1. **文生图**：直接根据首帧描述生成
   ```
   Vibe Video: Generate First Frames
   ```

2. **图生图（合成）**：使用主体+场景合成
   ```
   Vibe Video: Compose All First Frames
   ```

**选择建议**：
- 如果分镜指定了主体和场景，推荐使用合成方式
- 如果需要更精确的控制，使用文生图方式

#### 视频生成

**生成方式**：

1. **图生视频**（推荐）：
   - 使用首帧图片 + 视频提示词生成
   - 质量更高，更可控

2. **文生视频**：
   - 不使用首帧图片，完全依赖文本提示词
   - 适合快速原型

3. **首尾帧生视频**（高级）：
   - 使用首帧 + 尾帧图片生成
   - 实现更精确的画面控制

**生成选项**：

- **分辨率**：480P / 720P / 1080P（在设置中配置）
- **时长**：5秒 或 10秒（由分镜脚本决定）

### 3. 资源管理

#### 侧边栏资源视图

左侧活动栏的 **Vibe Video** 图标打开资源视图，显示：

- 📝 **剧本**：`剧本.md`
- 👤 **主体**：所有主体文件和图片
- 🎨 **场景**：所有场景文件和图片
- 📋 **分镜**：所有分镜脚本

- 🎬 **视频片段**：所有生成的视频
- 📎 **参考图**：用户自定义参考图

#### 右键菜单功能

**通用功能**：
- **复制相对路径**：复制文件相对路径，便于在分镜脚本中引用
- **在资源管理器中打开**：在文件管理器中定位文件
- **重命名**：重命名资源
- **删除**：删除资源

**生成功能**：
- **生成主体**：生成单个主体图片
- **生成场景**：生成单个场景图片
- **生成视频**：生成单个视频片段
- **根据首尾帧生成视频**：使用首尾帧生成视频

#### 资源状态指示

- ✅ **绿色对勾**：资源已生成
- ⚠️ **黄色警告**：资源缺失或有问题
- ❌ **红色错误**：生成失败

### 4. 配置管理

#### 查看当前配置

```
Ctrl+Shift+P → "Vibe Video: Show Current Config"
```

显示：
- 当前 Provider
- API Key 状态（已配置/未配置）
- API Key 前几位（用于确认）

#### 修改配置

**方法 1：通过设置界面**

```
Ctrl+, → 搜索 "vibevideo"
```

**方法 2：通过命令**

```
Ctrl+Shift+P → "Vibe Video: Configure Video AI"
```

#### 配置项说明

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `vibevideo.provider` | AI 服务商 | `tongyi-wanxiang` |
| `vibevideo.dashscope.apiKey` | DashScope API Key | 空 |

| `vibevideo.replicate.imageModel` | Replicate 文生图模型 | 空（使用默认） |
| `vibevideo.replicate.videoModel` | Replicate 视频生成模型 | 空（使用默认） |

## 分镜脚本编写规范

### 标准格式

```markdown
# 场景标题

- **时长**: 5秒 或 10秒（**只能是5秒或10秒**）
- **主体**: 角色1, 角色2（可选）
- **场景**: 场景名（可选）
- **参考图**: first-frames/xxx-first-frame.png, ref-img/xxx.jpg（可选）
- **首帧**: first-frames/xxx-first-frame.png（可选）
- **尾帧**: first-frames/xxx-last-frame.png（可选）

**提示词**：一段融合的完整描述，包含视频内容、声音（可选）、美学控制（可选）和风格化（可选）。
```

### 字段说明

#### 1. 时长（必需）

- ✅ **只能是 5秒 或 10秒**
- ❌ 不允许其他时长（如 3秒、8秒、15秒等）
- 如果场景内容较长，应拆分为多个 5秒 或 10秒 的分镜

#### 2. 主体（可选）

- 列出分镜中涉及的主要角色或对象
- 格式：`角色1, 角色2`
- 如果分镜中没有固定角色，可省略
- 用于确保角色外观一致

#### 3. 场景（可选）

- 指定分镜的背景场景
- 格式：`场景名`（对应 `scenes/` 目录中的文件）
- 用于复用场景资源

#### 4. 参考图（可选，推荐）

**推荐使用**：使用参考图可以让生成的内容更加可控。

**格式**：
- 首帧图片：`first-frames/xxx-first-frame.png`
- 用户自定义：`ref-img/xxx.jpg`
- 多张图片：用逗号分隔

**示例**：
```markdown
- **参考图**: first-frames/01-opening-first-frame.png, ref-img/product.jpg
```

**使用建议**：
- ✅ **使用参考图**：生成内容更可控，画面更符合预期
- ⚠️ **不使用参考图**：完全依赖文本描述，生成结果可能有一定随机性

#### 5. 首帧（可选）

- 指定首帧图片路径
- 格式：`first-frames/xxx-first-frame.png`
- 用于图生视频

#### 6. 尾帧（可选，高级功能）

- 指定尾帧图片路径
- 格式：`first-frames/xxx-last-frame.png`
- 用于首尾帧生视频，实现更精确的画面控制
- **注意**：尾帧通常是下一个分镜的首帧

#### 7. 提示词（必需）

**重要约束**：
- ❌ **禁止**分条输出，如：
  ```markdown
  **视频提示词**：...
  **声音提示词**：...
  **美学控制**：...
  ```
- ✅ **必须**融合成一段连贯的自然语言描述

**应包含的内容**（自然地融合在描述中）：

**视频内容**：
- **运动描述**：结合图像中的元素，描述其动态过程（如奔跑、打招呼、挥手、转身、跳跃）
- **运镜描述**：镜头运动（如"镜头推进"、"镜头拉远"、"镜头向右移动"、"手持镜头"、"跟随镜头"、"固定镜头"）

**声音**（可选）：
- **人声**：角色说话的内容 + 情绪 + 语调 + 语速 + 音色
- **音效**：音源材质 + 行为 + 环境音（如脚步声、敲门声、物体坠地、撞击声）
- **背景音乐**：风格 + 情绪（如情绪音乐、卡点音乐、轻音乐）

**美学控制**（可选）：
- **光源类型**：日光、人工光、月光、实用光、火光
- **光线类型**：柔光、硬光、顶光、侧光、背光
- **时间段**：白天、夜晚、黄昏、日落、黎明

**风格化**（可选）：
- **视觉风格**：写实、卡通、水彩、油画、赛博朋克
- **色彩风格**：暖色调、冷色调、高饱和度、低饱和度
- **画面质感**：电影感、纪录片感、广告感

**示例**：

```markdown
**提示词**：镜头缓慢推进，展现城市街道的繁华景象，主角从远处走来，微笑着向镜头挥手，背景音乐轻松愉快，阳光透过高楼洒下，营造出温暖明亮的氛围。
```

```
MyVideoProject/
├── 剧本.md                   # 主剧本文件

├── scenes/                   # 场景
│   ├── 城市街道.md           # 场景描述
│   ├── 城市街道.png          # 生成的场景图片
│   └── ...
├── storyboards/              # 分镜脚本
│   ├── 01-opening.md
│   ├── 02-showcase.md
│   └── ...
├── first-frames/             # 首帧
│   ├── 01-opening-first-frame.md  # 首帧描述
│   ├── 01-opening-first-frame.png # 生成的首帧图片
│   └── ...
├── video-clip/               # 视频片段
│   ├── 01-opening.mp4
│   └── ...
├── ref-img/                  # 参考图（可选）
│   └── product.jpg
└── output/                   # 最终输出（可选）
    └── final.mp4
```

#### 命名规范

**分镜脚本**：
- 格式：`01-opening.md`、`02-showcase.md`
- 使用数字前缀确保顺序
- 使用英文或拼音，避免特殊字符

**首帧文件**：
- 描述：`01-opening-first-frame.md`
- 图片：`01-opening-first-frame.png`
- 尾帧：`01-opening-last-frame.png`（可选）

**主体/场景**：
- 使用有意义的名称：`主角.md`、`城市街道.md`
- 避免重名

### 资源复用

#### 主体复用

同一个主体可以在多个分镜中使用，确保角色外观一致：

```markdown
# 分镜 1

- **主体**: 主角  # 使用相同的主体，外观一致
```

3. 确认删除

如果对生成的资源不满意：

1. 删除旧资源（图片或视频）
2. 重新执行生成命令
3. 系统会重新生成

## 常见问题

### 安装与配置

**Q: 如何检查扩展是否安装成功？**

A: 在 VS Code 左侧活动栏应该能看到 **Vibe Video** 图标（🎬）。如果看不到，尝试：
1. 重新加载窗口：`Ctrl+Shift+P` → `Developer: Reload Window`
2. 检查扩展是否已启用

**Q: API Key 配置在哪里？**

A: 
- 用户设置：`C:\Users\YourName\AppData\Roaming\Code\User\settings.json`（Windows）
- 工作区设置：`.vscode/settings.json`（项目目录）

**Q: 如何验证 API Key 是否正确？**

A: 
1. 执行 `Vibe Video: Show Current Config` 查看配置状态
2. 尝试生成一个首帧图片，如果成功说明配置正确

**Q: 可以使用本地部署的模型吗？**

A: 可以！配置 `vibevideo.dashscope.baseUrl` 为本地服务地址。详见 [本地部署配置指南](本地部署wan2.5配置指南.md)

### 项目初始化

**Q: 初始化项目会覆盖现有文件吗？**

A: 不会。如果项目已初始化，会提示是否重新初始化。重新初始化会：
- 重新创建目录结构（如果不存在）
- 重新生成配置文件（会覆盖）
- 不会删除已有资源

**Q: 可以在已有项目中初始化吗？**

A: 可以。初始化不会影响现有文件，只会添加必要的目录和配置文件。

### 分镜脚本

**Q: 分镜时长可以是其他值吗（如 3秒、8秒）？**

A: **不可以**。分镜时长只能是 **5秒 或 10秒**。如果场景内容较长，应拆分为多个分镜。

**Q: 分镜脚本必须包含哪些字段？**

A: 
- **必需**：时长、提示词
- **推荐**：主体、场景、参考图、首帧
- **可选**：尾帧（高级功能）

**Q: 提示词可以分条列出吗？**

A: **不可以**。提示词必须是一段融合的完整描述，不能分条列出。例如：

❌ **错误**：
```markdown
**视频提示词**：镜头推进
**声音提示词**：背景音乐轻松
**美学控制**：阳光明亮
```

✅ **正确**：
```markdown
**提示词**：镜头缓慢推进，背景音乐轻松愉快，阳光透过高楼洒下，营造出温暖明亮的氛围。
```

**Q: 如何引用参考图？**

A: 在分镜脚本中使用相对路径：
```markdown
- **参考图**: ref-img/product.jpg
```

或者引用首帧图片：
```markdown
- **参考图**: first-frames/01-opening-first-frame.png
```

### 资源生成

**Q: 生成图片/视频需要多长时间？**

A: 
- 图片生成：通常 10-30 秒
- 视频生成：通常 1-5 分钟（取决于分辨率和时长）

**Q: 生成失败怎么办？**

A: 
1. 检查 API Key 是否正确
2. 检查网络连接
3. 检查 API 额度是否充足
4. 查看 VS Code 输出面板的错误信息

**Q: 可以同时生成多个资源吗？**

A: 目前是串行生成，一次生成一个。批量生成会依次处理所有资源。

**Q: 生成的图片质量不满意怎么办？**

A: 
1. 删除旧图片
2. 优化提示词（更详细的描述）
3. 重新生成

**Q: 主体图片为什么是白色背景？**

A: 白色背景便于后续合成。主体图片主要用于与场景图片合成首帧，白色背景可以更好地融合。

### 视频生成

**Q: 图生视频和文生视频有什么区别？**

A: 
- **图生视频**：使用首帧图片 + 提示词，质量更高，更可控（推荐）
- **文生视频**：不使用图片，完全依赖文本提示词，适合快速原型

**Q: 如何使用首尾帧生成视频？**

A: 
1. 在分镜脚本中添加 `- **尾帧**: first-frames/xxx-last-frame.png`
2. 生成尾帧图片
3. 执行 `Vibe Video: Generate All Videos From First Last Frame`

**Q: 视频分辨率如何选择？**

A: 
- **480P**：低质量，生成快，文件小（适合测试）
- **720P**：平衡质量，推荐使用
- **1080P**：高质量，生成慢，文件大（适合最终输出）

### 其他问题

**Q: 可以导出项目吗？**

A: 项目本身就是文件夹，可以直接复制或压缩分享。

**Q: 如何备份项目？**

A: 
1. 复制整个项目文件夹
2. 或使用 Git 版本控制（建议添加 `.gitignore` 忽略生成的资源）

**Q: 支持哪些视频格式？**

A: 目前生成的是 MP4 格式。

**Q: 可以自定义 AI 模型吗？**

A: 
- **通义万相**：使用固定模型（wan2.5 系列）
- **Replicate**：可以在设置中自定义模型

## 最佳实践

### 1. 剧本编写

- 时长固定（5秒或10秒）
- 提示词详细且融合
- 合理使用主体和场景
- 包含参考图提高可控性

**❌ 避免**：
- 时长不规范
- 提示词分条列出
- 缺少必要字段
- 描述过于简略

### 3. 提示词编写

**✅ 好的提示词**：
- 融合所有元素（视频内容、声音、美学、风格）
- 描述具体、详细
- 使用专业术语（运镜、光线等）
- 自然流畅，像讲故事

```markdown
镜头缓慢推进，展现城市街道的繁华景象，主角从远处走来，微笑着向镜头挥手，背景音乐轻松愉快，阳光透过高楼洒下，营造出温暖明亮的氛围，画面采用电影质感，色彩饱和度高。
```

- 过于简略："一个人走路"
- 分条列出：视频提示词...声音提示词...
- 缺乏细节：没有运镜、光线、风格描述

### 4. 资源管理

**✅ 好的实践**：
- 使用有意义的命名
- 复用主体和场景
- 定期清理不需要的资源

- 不清理临时文件

**✅ 好的流程**：
1. 快速生成初版
2. 审核并标记问题
3. 优化提示词或重新生成

### 6. 成本控制

**✅ 节省成本**：
- 复用主体和场景
- 先测试小规模生成
- 使用 480P 测试，720P 最终输出
- 合理使用参考图提高成功率

**❌ 浪费成本**：
- 重复生成相同资源
- 不审核就批量生成
- 使用过高质量（1080P）测试

## 进阶技巧

### 1. 使用参考图

参考图可以让生成的内容更加可控。

**添加参考图**：
1. 将图片放在 `ref-img/` 目录

   ```markdown
   - **参考图**: ref-img/product.jpg
   ```

**使用场景**：
- 产品展示：使用产品照片作为参考
- 风格参考：使用风格图片作为参考
- 精确控制：使用首帧图片作为参考

### 2. 使用首尾帧生成视频

首尾帧生成视频可以实现更精确的画面控制。

**步骤**：
1. 在分镜脚本中添加尾帧字段：
   ```markdown
   - **尾帧**: first-frames/01-opening-last-frame.png
   ```
2. 生成尾帧图片（可以手动创建或使用 AI 生成）
3. 执行首尾帧生成视频命令

**适用场景**：
- 需要精确控制画面变化
- 场景转换需要平滑过渡
- 关键动作需要精确控制

### 3. 优化提示词

**技巧 1：使用专业术语**

- 运镜：推进、拉远、跟随、环绕、固定
- 光线：柔光、硬光、顶光、侧光、背光
- 风格：电影感、纪录片感、广告感

**技巧 2：融合所有元素**

不要分条列出，而是融合成一段描述：
```markdown
镜头缓慢推进，主角从远处走来，微笑着向镜头挥手，背景音乐轻松愉快，阳光透过高楼洒下，营造出温暖明亮的氛围。
```

**技巧 3：添加细节**

- 动作细节：如何走路、如何挥手
- 情绪细节：表情、姿态
- 环境细节：天气、时间、氛围

### 4. 批量处理技巧

**批量生成顺序**：
1. 先生成主体（确保角色一致）
2. 再生成场景（创建环境）
3. 然后生成首帧（组合主体和场景）
4. 最后生成视频（基于首帧）

**批量生成建议**：
- 先测试单个资源，确认质量后再批量生成
- 使用 480P 测试，确认无误后再用 720P 生成最终版本
- 定期保存项目，避免意外丢失

### 5. 项目组织技巧

**目录结构**：
- 使用数字前缀确保分镜顺序
- 使用有意义的名称便于查找
- 保持命名一致性

**版本控制**：
- 使用 Git 管理项目
- 添加 `.gitignore` 忽略生成的资源
- 定期提交重要节点

**备份策略**：
- 定期备份项目文件夹
- 重要资源单独备份
- 使用云存储同步

### 6. 调试技巧

**查看日志**：
1. 打开 VS Code 输出面板：`View → Output`
2. 选择 "Vibe Video" 通道
3. 查看详细的生成日志

**常见错误处理**：
- **API Key 错误**：检查配置是否正确
- **网络错误**：检查网络连接
- **额度不足**：检查 API 额度
- **生成失败**：查看错误信息，优化提示词后重试
